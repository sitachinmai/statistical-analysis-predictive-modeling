# Week 3: Statistical Analysis and Predictive Modeling Using R

## Project Overview
This project focuses on statistical analysis and predictive modeling using the R programming language. The Iris dataset is used to perform exploratory statistical analysis, hypothesis testing, and classification.

## Objectives
- Perform descriptive statistical analysis.
- Analyze correlations and test normality assumptions.
- Conduct hypothesis testing using one-way ANOVA.
- Build a multinomial logistic regression classification model.
- Evaluate model performance using cross-validation, a confusion matrix, accuracy, precision, recall, and F1-score.
- Visualize actual and predicted flower species.

## Dataset
The project uses the built-in Iris dataset in R. It contains 150 observations from three flower species: Setosa, Versicolor, and Virginica. The dataset includes sepal length, sepal width, petal length, and petal width.

## Tools and Technologies
- R programming language
- Google Colab
- ggplot2
- nnet
- caret

## Analysis and Modeling
The project includes descriptive statistics, Pearson correlation testing, the Shapiro–Wilk normality test, one-way ANOVA, multinomial logistic regression, five-fold cross-validation, and model performance evaluation.

## Visualizations
- Confusion Matrix Heatmap
- Actual vs Predicted Species Bar Chart

## Files
- `Week3_Statistical_Analysis_Report.docx` — detailed project report

## Conclusion
This project demonstrates how statistical methods and classification models can be used to analyze data and predict flower species. Model evaluation metrics help assess predictive performance and identify opportunities for improvement.
